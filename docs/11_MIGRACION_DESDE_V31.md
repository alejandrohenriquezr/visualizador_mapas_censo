# Migración desde V31

Este repositorio limpio se genera como una COPIA del proyecto operativo. El origen no se modifica.

La estructura histórica `docker5/`, `scripts5/`, `docker-compose.5svc.yml`, parches V2...V31, respaldos y artefactos de instalación no se copian. Sus componentes vigentes quedan consolidados en `frontend/`, `backend/`, `cartography/`, `database/`, `scripts/` y `docs/`.
