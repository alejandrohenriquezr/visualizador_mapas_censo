# Seguridad y gobernanza

- No subir microdatos, FileGDB, `.env`, contraseñas ni SQLite a GitHub.
- PostgreSQL, backend, Ollama y cartography no publican puertos al host por defecto.
- Para acceso de intranet publicar únicamente el puerto de frontend.
- Definir licencia institucional antes de hacer público el repositorio.
- Mantener trazabilidad de cambios en reglas estadísticas y diccionarios.
- Las fórmulas oficiales deben quedar documentadas y testeadas; el LLM no reemplaza esa gobernanza.
