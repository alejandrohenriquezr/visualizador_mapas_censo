# Microdatos

Esta carpeta no se versiona. Descarga la base oficial de microdatos Parquet desde la [página de resultados del Censo 2024 del INE](https://censo2024.ine.gob.cl/resultados/). Consulta los pasos detallados en [Instalación y requisitos](../docs/00_INSTALACION.md).

Extrae o copia aquí los tres archivos con estos nombres:

- `personas_censo2024.parquet`
- `hogares_censo2024.parquet`
- `viviendas_censo2024.parquet`

El backend monta los archivos en modo de solo lectura. No los subas al repositorio: son datos censales descargados por separado y están excluidos de Git.
